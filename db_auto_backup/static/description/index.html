Automatic Database Backup

Automate your Odoo backups — securely and effortlessly!

The Automatic Database Backup module enables scheduled and manual database backups directly from your Odoo interface. Never lose your data again — keep your system safe with automatic daily, weekly, or custom interval backups.

✨ Key Features

  • 📅 Automated Scheduled Backups using cron jobs (daily, weekly, etc.)
  • 💾 Local Storage support (local folder)
  • 🧾 Backup Management Interface — view, download, or delete backups
  • 📨 Email or WhatsApp Notifications for success/failure (optional)
  • 🔐 Secure Backup Handling with file integrity checks
  • 📊 Backup Logs and History for full traceability
  • ⚙️ Simple Configuration

🧭 How It Works

  1. Install the module from the Apps menu.
  2. Go to Automatic Database Backup ➜ Backup Configuration.
  3. Configure backup location and frequency.
  4. Let the system automatically generate backups as per schedule.
  5. You can also manually trigger a backup from the form view.
